# 🖤 HARAWKAN | Anonymous Messages & Vibe

> A modern, sleek, and fully interactive web application designed for sending secret anonymous messages, paired with custom vibes, song links, and animated stickers.

---

## ✨ Features

- **Interactive Marquee:** A smooth, non-translatable text ticker featuring bilingual vibes (English & Moroccan Darija).
- **Interactive Emoji Background:** Freely drag and move background emojis around the screen.
- **Dynamic Pro Logo:** Eye-catching gradient animated header.
- **Secret Messaging System:** Clean UI to send anonymous text notes and music links (Spotify/YouTube).
- **Animated Sticker Selector:** Choose from a wide variety of animated webm/webp stickers with a dedicated preview display.

---

## 🛠️ Built With

- **HTML5** (Structure & Protection against auto-translation)
- **CSS3** (Modern styling, glassmorphism, responsive grid, custom fonts)
- **JavaScript (ES6+)** (DOM manipulation, interactive drag-and-drop, dynamic preview logic)
